一、报告一共需要哪几张 RTL 仿真波形图？
--------------------------------------------------------------------------------
整篇技术报告只需要 2 张核心 RTL 仿真验证波形图（正好对应报告中的【图 5】与【图 7】）：

1. 【图 5】（第 2.3.3 节）：M5 相对饱和度比例判色与二维连通带统计仿真波形
   - 对应源码：src/alg_color_gate.v + src/alg_runlen_bbox.v
   - 对应激励：tb/tb_fig5_m5_color_bbox.v
   - 对应脚本：run_fig5_m5.do
   - 核验亮点：
     (1) 白墙高亮度背景 (210,205,200) 因相对饱和度不足被 w_rel_base=0 直接拦截；
     (2) 背景孤立 8px 红杂点在 r_gap 计满 GAP_MAX=2 后触发 w_gap_out 关段，且因段长
         w_run_len=8 < MIN_RUN(32) 被丢弃；
     (3) 扫描红色目标物块 (Row 10~15, X=460..503) 时，物块表面 1 拍反光空洞被 r_gap=1
         自动桥接不断段，跨行有效行数 b_rows 累加到 6 行，帧末锁存输出 O_valid=1、
         O_x0=460、O_x1=503、O_y0=10、O_y1=15。

2. 【图 7】（第 2.3.5 节）：AWB 20 轮恢复余数迭代除法器与自研 I2C 从机仿真波形
   - 对应源码：src/awb_div20_core.v (提取自 awb.v) + src/gim_i2c_slave.v
   - 对应激励：tb/tb_fig7_awb_and_i2c.v
   - 对应脚本：run_fig7_awb_i2c.do
   - 核验亮点：
     (1) AWB 迭代除法器：div_cnt 从 0 到 20 逐拍迭代移位减法，第 20 轮结束拉高 div_done，
         精确锁存 Q4.16 格式红蓝通道白平衡增益 in_r_r1=20'h14CCC (1.30x)、in_b_r1=20'h123D7 (1.14x)；
     (2) I2C 从机 (0x50)：像素域帧末锁存目标中心 (488, 281) 并经三级同步触发 w_upd 更新影子寄存器，
         主机连读 0x00~0x04 依次读出 0xE8, 0x01, 0x19, 0x01, 0x01；当拨下 B4 追踪开关
         (I_track_en=0) 后，无需等待下一帧，再次读取 0x04 (VALID) 立即变为 0x00，读 0x0F 返回 0x5A。

二、在 ModelSim 中一键导入并截图的操作步骤（仅需 30 秒）
--------------------------------------------------------------------------------
1. 将本压缩包解压到任意无中文空格路径（或任意本地目录）；
2. 打开 ModelSim，点击顶部菜单：File -> Change Directory...，选择解压后的文件夹；
3. 在 ModelSim 底部的 Transcript 命令行窗口中：
   - 输入：do run_fig5_m5.do   回车 -> 自动编译、仿真并弹出配置好分组和配色的【图 5】波形窗口！
   - 截图保存替换报告中的图 5（可使用 Wave 窗口 File -> Export -> Image... 或 Win+Shift+S 截图）；
   - 输入：do run_fig7_awb_i2c.do 回车 -> 自动编译、仿真并弹出配置好分组和配色的【图 7】波形窗口！
   - 截图保存替换报告中的图 7。
